### Wire and IO decisions

Use existing EYL Value lists, unsigned integers, text/bytes, null/bool; no maps. Header is closed list `["eyleme.memory",1,project,profile,schema,profile_revision,profile_identity_bytes]`. Each subsequent event is `["memory.event",1,generation,operation,record_id,expected_revision_or_null,record_revision_or_null,record_fields_or_null]`. Operation is put/review/observe/tombstone. Record_fields order is [project,id,revision,profile,schema,kind,origin,admission,observed_at,valid_from,expires_at,confidence_or_null,subject_or_null,predicate_or_null,typed_object_or_null,episode_status_or_null,episode_text_or_null,source_pin_list,projection_pin,embedding_blob_or_null]. Typed object is [tag,value], SourcePin is [project,id,put_digest], projection pin is [project,id,put_digest]; profile header identity is the canonical EYL encoding of [schema,profile_revision,predicate_profiles,representation_fields]. Do not silently add optional field positions; a schema revision change must remain explicit. Unknown tag/arity/version rejects. Store F32 vectors as one <=4096-byte little-endian IEEE754 blob, not 1024 Value nodes; reject nonfinite/wrong dimension/norm with existing G70 admission, no new kernel. Profile identity includes all representation/predicate fields. Canonical schema validation binds the journal to the full expected profile.
