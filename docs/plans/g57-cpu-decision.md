## Review Focus

- Tokenizer JSON equality hides a different config, vocabulary or parent identity: Task1/3 must reject cross-profile encoded tokens before forward.
- Chunked attention normalizes locally or checks stop only while precharging: Task2 must compare a4096-position reduction against an independent full-domain result and cancel during computation.
- Pair reuse resets total work or retains KV/output allocations: Task2/3 test exact aggregate one-below failure, pair-order invariance and constant shared-weight storage.
- Rounded half-boundaries, duplicate IDs and tied options produce a spurious winner: Task3 tests frozen arithmetic, exact floor/margin and tie/unknown-score abstention.
- Cancellation after a completed pair leaks a partial batch or cached result: Task3/4 cancel during the next pair and require no accepted result plus invalid-cache rejection.
